# Area map — verification of rows A01–A10

**Status:** draft from `ic2-conquest`, awaiting promotion. Companion to `findings/2026-10-05-player-facing-feature-inventory.md` rows A01–A10. Ten rows that share `TAreaMap` (the area-map child window) and `TFindCity` (the A08 dialog). One consolidated draft.

**Tags.** All ten rows = `[confirmed]` or `[derived]` per inventory (mixed; mostly `[confirmed]` with `[derived]` for A08's address-underlying). This draft tightens the cell-level evidence without re-tagging.

## Answer

### A01 — Toggle colour

`TAreaMap/Panel1/sb_areatog` (`TSpeedButton`, hint=`Toggle colour`, OnClick=`ToggleMap`). The area-map child form also has form-level event handlers (`OnCloseQuery=CheckQuit`, `OnCreate=InitializeForm`, `OnKeyDown=KeyPressed`, `OnMouseDown=AreaMapClick`, `OnPaint=PaintForm`, `OnResize=ResizeForm`, `OnShow=InitializeForm` — reproduced verbatim from `form_controls.tsv`).

The "two clicks clear the drawn markers" detail is a runtime behaviour of `ToggleMap` (a single call swaps mono / terrain; a second call clears the markers). `explore/b1.log` carries the live evidence: *"area-map hash returns to the cleared value after two clicks."* Help topic 50 ("Area map") cites *"If you click with the left mouse button on the area map the position on the unit map will be adjusted accordingly."* and the "If the area map becomes cluttered it can be cleared by clicking TOGGLE COLOUR twice" detail.

## What does not match — three open notes

1. **A08's `TFindCity_OK` function address** — the inventory's row prose cites `X:TFindCity_OK, TAreaMap_ShowFindCity`, but the function-table search didn't surface a `TFindCity_OK` row at any address. The `TFindCity` form's `btn_ok` row in `form_controls.tsv` has `OnClick=OK`, which routes through Delphi's default handler — possibly the form doesn't have a named OK method (a Delphi inline OK of a button without an explicit `OnClick` is unusual but possible). Carrying forward; reproducing the OK handler may need capstone or a fresh extract.
2. **A10's "rectangle colour"** — the rectangle's fill colour is the viewed nation's background colour, but the rectangle's outline (and where its corners sit relative to the Unit-map window) isn't pinned. The 13×13 window position from `state/sav.py` `view = [+0x488, +0x486]` and the unit-map paint box `(337 + 32·(x-ox) + 16, 126 + 32·(y-oy) + 16)` (per `coverage.md §2`) defines the geometry; carrying as `[derived]` carry-over.
3. **A07's "All mercenaries" speed-button hint** is `All mercenaries` (verbatim); the **menu item** is also `All mercenaries` (mn_Allmercs). Both surfaces reuse the same `ShowMercsAll` handler at `0x0043e510`. Markers drawn by this handler are visible in `FI_b1_22_show_all_mercenaries.png`. No actual gap, just noting for the reproduction path.

## Method

- **Form + function extraction.** Same toolchain. `TAreaMap`'s form-level `OnMouseDown=AreaMapClick` and `OnKeyDown=KeyPressed` are the A09 / A10 dispatchers; the function-list rows back them up.
- **Panel1 sb_* speed buttons** all reproduced verbatim from `form_controls.tsv`. The 12 speed buttons + the menu submenu + the 11 merc handler functions are the only data needed for A01–A10.
- **`TFindCity`** form reproduced in full (form + 16 nation buttons + 1 listbox + 1 OK button + 3 bevels + 1 label).
- **Reproduction cells.** Five `MANIFEST-batch1.txt` screenshot hashes for A07 / A08 are recorded in the cells; `MANIFEST-batch2.txt` carries the Shift+C / Shift+P live tests (cited under A02 / A03).
- **Tag scheme.** Same as the other drafts.

## Inferences

- **`TAreaMap` is the area-map child window** with a self-contained `Panel1` of 12 speed buttons (no external form-popup needed for A02–A07). The single form drives a 1-to-1 mapping from speed button ↔ menu item ↔ function handler (six Show<X> + six ShowMercs<X>); a reproduction can iterate the same array for both surfaces.
- **`TFindCity` carries 16 nation buttons + 1 listbox.** The listbox is `lbx_cities` (selected via `OnClick=ChangeCity`); the OK button confirms the selection. Reproducing requires populating `lbx_cities` per the current nation; coverage row §3 'Find city' has the wiring.

## What this does not establish

- A08's exact `TFindCity_OK` address (open note 1 above).
- A10's rectangle outline colour and corner geometry (open note 2).
