# Game menu — verification of rows G01–G04

**Status:** draft from `ic2-conquest`, awaiting promotion. Companion to `findings/2026-10-05-player-facing-feature-inventory.md` rows G01–G04. Four Game-menu items — End turn, New player, New nation, Abdicate — and the shared HumanLeaderFalls / Abdicate bridge `FUN_00449078 @ 0x00449078`. One consolidated draft.

**Tags.** G01, G02, G03, G04 = `[confirmed]`. The G04 confirmation box was opened and answered *No* under live Wine (inventory's prose: *"SS:FI_b1_10_game_abdicate.png (the box; answered No)"*).

## Answer

### G01 — End turn

`mt_Game/mn_Endturn` (form_controls row `PremierForm/MainMenu/mt_Game/mn_Endturn`, `TMenuItem`, caption=`End turn`, OnClick=`EndTurn`) routes to `TPremierForm_EndTurn @ 0x0045b0a8` (function_list.tsv). The confirmation box (only when a warning applies; see row D08 in the inventory) is the *End turn ?* form, opened by `TToEndTurn_InitializeForm @ 0x00459828`. The handler-side code in `TPremierForm_EndTurn` calls `FUN_00449078` (the same bridge as Abdicate / HumanLeaderFalls) when warnings apply.

Coverage: `coverage.md §1 'End turn' ✅` (`T_END_AUTO0721.SAV`). Order details per `findings/2026-10-02-unit-map-mouse-orders-and-tax-range.md`. The round-tick order is recorded in `R:decompiled-turn-and-calendar-sequencing.md` (the `[derived]` row prose cites it). Help topic 5 ("End turn"): *"Ends the current player's turn … the order of play is set at random at the beginning of every game."*

### G02 — New player

`mt_Game/mn_Newplayer` (form_controls row, OnClick=`NewPlayer`) routes to `TPremierForm_NewPlayer @ 0x0045b148`. Opens the `TPickLeaders` form — same form as row F02, same functions: `TPickLeaders_InitializeForm 0x004571a8` / `TPickLeaders_HumanOrComputer 0x0045730c` / `TPickLeaders_OK 0x00457404` / `TPickLeaders_Cancel 0x00457590`. **The cell-level extraction is in the F01–F06 draft under F02** (verified 16 nation panels × `cbx_<n>` + `ed_<n>` rows; same SHA-256 chain).

Live screenshot: `SS:FI_b1_08_game_newplayer.png` (`MANIFEST-batch1.txt`, hash `9e71836648df31c9a07608eb6279ff7daba306e3e865715a264525e7360b2cf6`) — the form opens, Rome ticked. Help topic 6 ("New player"): *"Lets a new player enter the game. Upto 16 players can play (or as many players as countries remain)."*

### G03 — New nation

`mt_Game/mn_Newnation` (form_controls row, OnClick=`NewNation`) routes to `TPremierForm_NewNation @ 0x0045b198` (function_list.tsv). The yes/no prompt is at `dump_string_literals.v2.tsv` row 462: `"Are you sure you want to lead a different nation ?"` (in `TPremierForm_NewNation 0x0045b198`). Yes calls into the leaders-pick flow; *"Yes not run"* in the inventory's prose carries forward as `[derived]` for the post-Yes path.

Live screenshot: `SS:FI_b1_09_game_newnation.png` (`MANIFEST-batch1.txt`, hash `65e975561c4124d87ed581b38fbf533b2b80148c390e1f551ea5892d0db07972`) — the box, answered No. Help topic 7 ("New nation"): *"Allows a leader to desert their nation in favour of another."*

### G04 — Abdicate

`mt_Game/mn_Abdicate` (form_controls row, OnClick=`Abdicate`) routes to `TPremierForm_Abdicate @ 0x0045b24c` (function_list.tsv). Yes calls `FUN_00449078 @ 0x00449078` (function_list.tsv — the single bridge to "make the nation drop out of human control") then `TPremierForm_EndTurn` (the handler at `0x0045b0a8` per the inventory's prose). The yes/no prompt is at `dump_string_literals.v2.tsv` row 463: `"Are you sure you want to abdicate ?"` (in `TPremierForm_Abdicate 0x0045b24c`).

The `FUN_00449078` shared function is also reached from `THumanFalls_InitializeForm @ 0x00455e38` (V03 / V04 / G04 — the Eliminated / Deposed paths). Per `R:decompiled-diplomacy-peace-terms-and-instant-battles.md 'Victory condition'`: *"Abdicate and HumanLeaderFalls share FUN_00449078"*. Help topic 8 ("Abdicate"): *"Resign the leadership of your nation. If only 1 person is playing then this ends the current game."*

Live screenshot: `SS:FI_b1_10_game_abdicate.png` (`MANIFEST-batch1.txt`, hash `3b758258e8eed4103575ab27f1b8ffb3e5d1db0b0e9239c62f681a7e59883567`) — the box, answered No.

## What does not match — three open notes

1. **G03's Yes is `[derived]` (inventory's tag): "Yes not run".** The No branch is reproduced (live save + screenshot); the Yes branch would need a separate test that opens `TPickLeaders` from the New-nation path and writes a different leader flag. The two-human-seats finding has the multi-leader setup but is reached via the `New player` path (G02), not the `New nation` path. **Recorded as not-yet-verified; not a blocker.**
2. **G01's "End turn ?" box only when a warning applies.** The handler at `TPremierForm_EndTurn @ 0x0045b0a8` checks for the warning conditions before opening the form. The conditions list is row D08 ("End turn ?" warning lines, `[derived]` carry-over) — five warning lines, none of them in `dump_string_literals.v2.tsv` (per the D01–D11 draft's open notes). The 5-warning-list is what the End-turn-with-warning test covers; the no-warning fast-path is the default. **Same open note carried forward.**
3. **G04's Yes-to-`FUN_00449078` then to `EndTurn` chain** is in the inventory's prose as `[code, Yes not run]` — the harness hasn't exercised a Yes-to-Abdicate. The single-human Yes would end the game; a multi-human Yes would just turn the seat AI. Either is fine for reproduction; neither is recorded on a save yet. **Recorded as not-yet-verified.**

## Method

- **Form + function + literal extraction.** Same toolchain as the H/MM/D/K/M/F drafts. All four `mt_Game/mn_*` menu items reproduced verbatim from `form_controls.tsv` (the four-row batch `mt_Game` parents it under). Function handlers reproduced verbatim from `function_list.tsv` with their literal addresses. Confirmation-box strings reproduced verbatim from `dump_string_literals.v2.tsv` rows 462–463.
- **Live evidence.** `MANIFEST-batch1.txt` carries the SHA-256 chain for `FI_b1_08_game_newplayer.png` (G02), `FI_b1_09_game_newnation.png` (G03), `FI_b1_10_game_abdicate.png` (G04). Coverage.md §1 'End turn' is the G01 live test row.
- **`FUN_00449078` bridge.** Reproduced verbatim from `function_list.tsv`; the inventory's prose says it is reached from `TPremierForm_Abdicate` and from `THumanFalls_InitializeForm`, and the research-side `R:decompiled-diplomacy-peace-terms-and-instant-battles.md 'Victory condition'` records the cross-reference.
- **TPickLeaders reuse.** F02's form (16 nation panels, `cbx_<n>` + `ed_<n>`) is the same dialog opened by `New player` (G02) and by `New` (F01). The cell-level verification of the form lives in the F01–F06 draft under F02; this draft cites that and the form's `OnClick=NewPlayer` here. **Recorded as a reference, not a duplication.**

## Inferences

- **The four `mt_Game` items share a single-form `mt_Game/mn_*` parent** — the capture pattern is identical to `mt_file/mn_*`. A reproduction can iterate over an array of `{caption, OnClick}` pairs and emit Delphi `TMenuItem` rows the same way for both menus.
- **G01 / G04 share the same handler-end: `TPremierForm_EndTurn`.** Abdicate goes via `FUN_00449078` to the same place, so a clone reproducing the Game menu can route G01 and G04 Yes-handlers through one bookend. F02 and F03 reuse the `TPickLeaders` form via two different entry points (`New player` and `New nation`); the form's `OnCreate` is the same either way.

## What this does not establish

- G04 Yes → `FUN_00449078` → seat-becomes-AI save diff (one of the open notes above).
- G01's warning-detection subroutine inside `EndTurn` (D08 row's five-warning-line strings; flagged for the same decompile pass).
