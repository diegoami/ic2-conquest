## A harness change v0.8.5 needed

v0.8.5's command interface refuses to save while a post-battle peace offer is pending: "Answer the pending peace treaty offer
(peace-yes / peace-no) before saving." The first campaign run (v1) stopped there, in carthage turn 3. Its partial folder
`campaigns/` is kept.
- The adapter (`difftest/remake_adapter/Program.cs`) now answers `peace-no` before a checkpoint save in that case, and logs
  the answer as a command row. This is what the original side's driver does (`end_turn(peace=False)`).
- The campaigns were rerun as v2 (`campaigns-v2/`). The order and statistics results are reused from v1
  (`recheck.py --reuse`).
- The v0.8.4 build never shows the offer, so its results are unaffected.
- So v0.8.5 now models the original's post-battle peace offer to the human, which v0.8.4 did not.
