# run-exp-g4-followups

The follow-up original-side checks of issue #83 (the open items of the g1 and g3 findings), letters A-L. Finding: `findings/2026-10-12-g4-followups.md`. Templates: `../run-exp-g1-original-checks/`, `../run-exp-g3-original-checks/`.

- **Runner:** `g4_checks.py <case> [args]` with `g4_lib.py` (copy of g3_lib plus `Poller`, `set_offer`, `set_queue`, `relations_dialog`). One fresh Wine process per case, fast rollingsave seed exe (patched), seed 12345, Xvfb :99 (case E: Xvfb :98 with xfwm4). Cases: `F` (save flag 0x4a0334 with a 10 ms memory poller), `C` and `C_real` (the other deposition disjuncts), `B` (trade refusals), `A` (mercenary hired in play), `D` (no free tile), `D2` `D3` `D4` `D5` (human and AI mobilise distance branches), `G` (storm roll away from an own city), `H` (two war armies), `I` (AI quarter income), `K <nat|p3> <n>` (offer eligibility), `J` (Greece's -8 relations), `L_probe` and `L <rounds>` (weather-painted rough sea), `E` (real X-button click).
- **Logs:** `g4_checks-<case>-<stamp>.jsonl`, one JSON line per step, never overwritten. `g4_checks-G-20261012-110607.jsonl` is an ATTEMPT STOPPED BY US (war-on staging, every "away" trial lost the fleet to "Carthage sinks fleet of Rome."; Rome is at war with Carthage and Gaul in the port save); `g4_checks-G-20261012-111026.jsonl` hung in File > Open on a 112-character staged name (kept as evidence of the long-name bug, near-arm trials still valid); the fixed run stages peace with both and uses short staged names (`g4_checks-G-20261012-115755.jsonl`, the one the G section cites). `g4_checks-L_probe-*.jsonl` reads the 20 weather centres.
- **Static:** `static_flag_xrefs.py` -> `static_flag_xrefs.txt` (check F, capstone over the unpatched exe); `make_code_extract.py` -> `code_extract_g4.txt` (line-numbered whole functions of the pinned dump; `code_extract_g4.v2.txt` adds `FUN_0044b4f8`, R9).
- **Analyses (offline, read the logs and the kept saves, write the next free version):** `analysis_D.py`, `analysis_G.py`, `analysis_I.py` (the finding cites `analysis_I.v5.txt`; `.txt`, `.v2`, `.v3`, `.v4` are earlier states of the script, kept), `analysis_J.py` (the finding cites `analysis_J.v3.txt`; `.txt` and `.v2` are earlier states, kept), `analysis_K.py`. When an analysis is re-run after a reviewer's blocker or non-blocker finding, the script is `.v<N>.py` and the output is the matching `.v<N>.txt`; older versions are kept (rule 6).
- **Helpers:** `summ.py` (quick look), `release_sync.py` (idempotent upload to release `run-exp-g4-followups`, skips files written in the last 90 s, records `release-sync-<stamp>.json`), `versioned.py`.
- **Binaries:** saves and screenshots in release `run-exp-g4-followups` (git-ignored `artifacts/run-exp-g4-followups/`); SHA-256 in `SAVES.sha256`. Staged saves carry `staged_<tag>` in their name; every measured autosave is kept as `<case>_<stamp>_autosaveNN_<tag>_t<turn>_AUTO<turn>.SAV`.
