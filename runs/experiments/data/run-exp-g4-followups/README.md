# run-exp-g4-followups

The follow-up original-side checks of issue #83 (the open items of the g1 and g3 findings), letters A-L. Finding: `findings/2026-10-12-g4-followups.md`. Templates: `../run-exp-g1-original-checks/`, `../run-exp-g3-original-checks/`.

- **Runner:** `g4_checks.py <case> [args]` with `g4_lib.py` (copy of g3_lib plus `Poller`, `set_offer`, `set_queue`, `relations_dialog`). One fresh Wine process per case, fast rollingsave seed exe (patched), seed 12345, Xvfb :99 (case E: Xvfb :98 with xfwm4). Cases: `F` (save flag 0x4a0334 with a 10 ms memory poller), `C` and `C_real` (the other deposition disjuncts), `B` (trade refusals), `A` (mercenary hired in play), `D` (no free tile), `D2` `D3` `D4` `D5` (human and AI mobilise distance branches), `G` (storm roll away from an own city), `H` (two war armies), `I` (AI quarter income), `K <nat|p3> <n>` (offer eligibility), `J` (Greece's -8 relations), `L_probe` and `L <rounds>` (weather-painted rough sea), `E` (real X-button click).
- **Logs:** `g4_checks-<case>-<stamp>.jsonl`, one JSON line per step, never overwritten. `g4_checks-G-20261012-110607.jsonl` is an ATTEMPT STOPPED BY US: every "away" trial lost the fleet to "Carthage sinks fleet of Rome." (Rome is at war with Carthage and Gaul in the port save); the fixed run stages peace with both (`g4_checks-G-20261012-111026.jsonl`). Its near-arm trials are valid but the finding cites the fixed run. `g4_checks-L_probe-*.jsonl` reads the 20 weather centres.
- **Static:** `static_flag_xrefs.py` -> `static_flag_xrefs.txt` (check F, capstone over the unpatched exe); `make_code_extract.py` -> `code_extract_g4.txt` (line-numbered whole functions of the pinned dump).
- **Analyses (offline, read the logs and the kept saves, write the next free version):** `analysis_D.py`, `analysis_G.py`, `analysis_I.py` (`analysis_I.txt`, `.v2`, `.v3` are earlier states of the script, kept; `.v4` is the one the finding cites), `analysis_J.py` (`.txt` first version, `.v2` final), `analysis_K.py`.
- **Helpers:** `summ.py` (quick look), `release_sync.py` (idempotent upload to release `run-exp-g4-followups`, skips files written in the last 90 s, records `release-sync-<stamp>.json`), `versioned.py`.
- **Binaries:** saves and screenshots in release `run-exp-g4-followups` (git-ignored `artifacts/run-exp-g4-followups/`); SHA-256 in `SAVES.sha256`. Staged saves carry `staged_<tag>` in their name; every measured autosave is kept as `<case>_<stamp>_autosaveNN_<tag>_t<turn>_AUTO<turn>.SAV`.
