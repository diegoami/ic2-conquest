# Gap analysis part G2: Area map, Unit map (Army, Fleet, City, view and selection), Map mouse actions, Dialogs reached from other dialogs

Original: Imperial Conquest 2 (1996). Remake: `imperial_conquest_2` v0.5.0 (37f3062), read-only clone `/home/diego/projects/ic2-remake-v050`. Inventory: `/home/diego/projects/imperial-conquest-2-research/docs/reports/2026-10-05-player-facing-feature-inventory.md` (rows A, UA, UF, UC, UM, MM, D). Original-side evidence comes only from the inventory's Evidence column and the findings it cites (the original game was not run). Refusal texts of the original: `findings/2026-10-05-refusal-texts-and-conditions.md` (R01-R57, P01-P13).

How to read the evidence column. "(CLI observed)" = a transcript `cli/g2_<tag>.txt` of `remake_cli.sh` (classical-faithful preset, seat rome, seed 1, scripts in `scripts/g2/`, saves `g2_<name>.sav` hashed in `SAVES.sha256`; `scripts/g2/diff_saves.py a b` prints the state difference of two saves). "(code reading)" = a `path:line` in the clone, not exercised. The Godot dialogs call the same engine commands as the CLI (`ComposeOk()` returns `split-army ...`, `army-transfer ...` etc.), so a CLI result is the engine rule the dialog ends in, but a dialog's own pre-checks and wording are code reading only (no Godot run). Everything in the CLI was run under `classical-faithful` only; `improved` was not run (embark over capacity trims there: `EmbarkArmyCommandHandler.cs:77-95`).

Severity scale: breaks play / blocks a normal game / fidelity only / cosmetic. Nothing in this part reaches "breaks play" or "blocks a normal game": every order of the part can be issued and succeeds in the CLI; the differences are rule details, refusal texts and designed UI choices.

Known issues are cited from `known_post_v050_issues.json` (130 entries). Issues cited more than once below: #721 and #801 (refusal and prompt wording), #802 (missing refusals: split a mercenary or several units, 100% mobilisation, transfer onto a full fleet, Join fleets order), #869 (moved units' slot order), #630 (Split army supply rebalance), #713 (disband-unit far from a city), #595 (disembark leaves moves), #583 (attack prompt No drops the selection), #720 (shortcuts), #723 (Toggle colour, Buy supplies caption), #714 (fleet purchase payment), #515 and #903 (excluded by the brief).
