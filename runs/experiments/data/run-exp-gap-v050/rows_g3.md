## What this does not establish

- Godot behaviour (End turn box, End of Game window, pending offer row, confirmation prompts) is code reading only; no UI was run.
- Every V/EG/E13-E16/E19 CLI result except the 250 BC fall is on a staged save, so natural frequencies (rebellion, deposition, offers) are not measured; the AI-driven events are only sampled in three seeds (1, 3, 7).
- The original side of rows E01-E29 is largely decompile ([derived]); "matches" means the remake agrees with the research report, not with a fresh original observation. Only E12, E18, E03 (partly), V01-V04 and EG01 have live-original evidence behind them.
- Siege, tactical battle, movement costs, recruitment dialog and diplomacy screens were touched only where a row required it.
- The `improved` preset was sampled only for E12 and V05.
