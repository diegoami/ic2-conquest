# run-exp-g1-original-checks

Original-side checks 2, 3, 5, 6, 7, 8, 9 and 10 of the v0.5.0 gap analysis (`../run-exp-gap-v050/rows_g1.md`, "Original-side checks needed"; issue #78). Finding: `findings/2026-10-11-g1-original-checks.md`.

- **Runner:** `g1_checks.py <case> [args]` with `g1_lib.py` (stamped unique names, OCR, L1 staging helpers, Balance sheet reader). One fresh Wine process per case, fast rollingsave seed exe (patched) unless the case says `original` (unpatched `Imperial Conquest 2.exe`), seed 12345. Cases: `G2_merc li|hc|hi`, `G2_fleet`, `G2_debt`, `G2_depose <tag> <treasury>`, `G3_cap natural_target3|own3`, `G5 patched|original`, `G6 patched|original game|nogame_menu|nogame_sysclose`, `G7 <seed>`, `G8 natural | low_both <save>`, `G9`, `G10`.
- **Logs:** `g1_checks-<case>-<stamp>.jsonl`, one JSON line per step, never overwritten. Notes: `G2_merc-...231938` (control + the `hc` staged merc that made the process unreadable: PermissionError on /proc/<pid>/mem, no result) and `-232204` (the same `hc` variant, same outcome); `G2_depose-...234640/713/745` are the first three runs (no box check; the End of Game box shows only in the screenshots), `-234836/911/946` repeat them recording the boxes; `G6-...233525` failed on the `&No` button text (runner fix), `-233735` hung in the unpatched run (killed by the timeout) and `-234520` is its re-run; `G10-...235532` and `-235656` read the news lines with a wrong offset (not used), `-235901` is the usable run.
- **Helpers:** `win_close.c` (posts WM_SYSCOMMAND SC_CLOSE: Xvfb has no window manager, so no X button), `g5_diff.py` -> `g5_diff.txt`, `g7_summary.py` -> `g7_summary.md`, `make_exe_strings.py` -> `exe_strings_g1.txt` (byte-exact literals with file offsets), `make_code_extract.py` -> `code_extract_g1.txt` / `code_extract_g1.v2.txt` (line-numbered decompile extract pinned to the dump SHA), `release_sync.py` (idempotent upload to the release), `versioned.py`.
- **Binaries:** saves and screenshots in release `run-exp-g1-original-checks` (git-ignored `artifacts/run-exp-g1-original-checks/`); SHA-256 in `SAVES.sha256`. Staged saves carry `staged_<tag>` in their name; staging is listed in each log's `staged` line.
