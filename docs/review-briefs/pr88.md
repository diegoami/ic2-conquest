## Blocking means (any one is enough; a blocking finding means rework, never approve)

1. Any Done-when line fails, is contradicted by evidence, or a reproduction
   command cannot be followed as documented.
2. A report claims more than the controls establish, mixes code/emulator/Wine/
   native provenance, treats a confounded case as an isolated control, hides a
   failed attempt, or attributes unrelated changes to the tested routine.
3. An observer changes original gameplay state or ABI in a way that invalidates
   its evidence; an analysis silently drops/renumbers draws, repairs fixtures,
   ignores a mismatch or versions away evidence without retaining the original.
4. A runner risks deleting/overwriting measured saves or killing another
   session's game, or bypasses #25's prerequisite gate. A proven bypass is
   blocking even when it appears to be an edge case.
5. Arithmetic, field offsets, thresholds, counter timing, source citations or
   machine-generated evidence assertions are demonstrably wrong.

Not blocking: wording/style preferences, explicitly bounded unconfirmed native
behavior and #25's deliberate external dependency, or defects in unchanged
project code that this PR neither introduces nor relies on. Explain the concrete
failure and evidence for every blocker; do not invent a new gameplay design.
