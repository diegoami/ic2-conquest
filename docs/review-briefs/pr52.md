## Blocking means
- a literal in the finding that differs from its call-site literal in the tracked code extract (spacing, punctuation, the space before "?", typos), or a literal not checked byte for byte by the audit;
- a condition or test order that its cited code lines do not support, or a [derived] claim presented as [confirmed], or a staged save presented as natural play;
- a claims-audit check whose expected value is typed into the checker instead of read from the finding and recomputed from the sources, or a doctored-input test that would still pass with a wrong claim;
- the catalogue's completeness claim (74 calls; 63 literals found = catalogued) not reproducible from the tracked extract or scan;
- a runner that clicks fixed screen coordinates, does not verify a click's effect (the effect may be verified by the box read or the save diff), retries more than twice, or clicks End turn twice blindly;
- a measured output overwritten or deleted (CLAUDE.md rule 6), a binary in git, a write to another repository, or a process killed by pattern.
Everything else (style, wording, extra coverage) is non-blocking.
